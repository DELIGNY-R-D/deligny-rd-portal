Gaia Live - questions fréquentes

Réponses factuelles publiées par DELIGNY R&D. Outil : https://deligny-r-d.github.io/gaia-live/.

Quel problème Gaia Live résout-il ?

Observer le monde réel en direct demande normalement de payer et d'agréger soi-même des clés API multiples.

Que fait Gaia Live exactement ?

Agrège 55 sources publiques automatiquement. Calcule des statistiques en direct (moyenne, écart-type, sparklines). Ajoute une nouvelle source en YAML, sans toucher au code.

Comment Gaia Live fonctionne-t-il techniquement ?

Ruby stdlib pur, zéro dépendance. API HTTP JSON servie par WEBrick. Sources keyless - aucune clé API requise pour le socle.

Quelles sont les limites connues de Gaia Live ?

Fraîcheur par source de 15 minutes par défaut, pas du vrai temps réel. La vitrine publique n'expose qu'un sous-ensemble du système complet.

À qui s'adresse Gaia Live ?

Curieux data. Observateurs du réel.
