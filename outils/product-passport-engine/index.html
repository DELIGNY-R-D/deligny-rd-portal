Product Passport Engine

Crée le passeport d'un produit — matière, fabrication, réparation, fin de vie — avec sa page imprimable et son QR code. Pensé d'abord pour les objets imprimés en 3D (lampes, pièces de rechange…).
100 % gratuit · aucun compte · rien n'est envoyé (tout se calcule dans ton navigateur) Limite honnête (v0) : ceci est un registre local à cette machine (localStorage du navigateur). Ce n'est pas une base partagée entre plusieurs appareils ou personnes — pour transférer un passeport ailleurs, utilise l'export/import JSON ou le fichier HTML téléchargé, qui EST le document.
