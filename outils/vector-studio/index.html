2 · Résultat vectoriel

Vectorise une image pour voir le résultat ici.
Édition : clique un chemin (aperçu ou liste) pour le sélectionner, reclique le chemin déjà sélectionné pour afficher ses points d'ancrage — glisse un point pour le déplacer, le tracé SVG se met à jour en direct. Seuls les points d'ancrage bougent (pas les poignées de courbure Bézier) : sur les segments courbes, la courbe autour du point déplacé peut se déformer un peu. Pour une édition de courbes fine, il faut un vrai éditeur vectoriel (Illustrator, Inkscape).
—
Échelle DXF : pixels bruts (1 unité DXF = 1 px source). Renseigne la largeur réelle de l'image pour exporter en millimètres.
Vectorisation automatique par régions de couleur — approximative, ne remplace pas un tracé manuel précis pour des besoins de découpe critique. L'export DXF encode les chemins en polylignes 2D ; par défaut les unités sont les pixels de l'image source — renseigne la largeur réelle (mm) pour exporter à l'échelle. Aucune donnée ne quitte ton navigateur.
